# 브라우저 콘솔 (`console.html`)

Python 없이 **브라우저에서 인허가 CSV를 바로 분석**하는 화면. `src/` 파이프라인과 같은
파싱·집계 규칙을 JavaScript로 옮겨 놓은 것이라 결과가 일치한다.

- CSV 원본은 **브라우저 밖으로 나가지 않는다.** 파싱·집계 전부 클라이언트에서 끝난다.
- ZIP 자동 해제(JSZip), CP949·UTF-8 인코딩 자동 판별, 한글·영문 헤더 모두 인식.
- 계산된 요약만 아티팩트 저장소에 남겨 다음 방문 때 복원한다(원본 CSV는 저장하지 않는다).
- 데이터를 넣기 전에는 **예시(합성) 데이터**로 열리며 화면에 그렇게 표시된다.

Artifact로 발행해 쓰거나, 이 파일을 그대로 브라우저에서 열어도 된다
(직접 열면 저장·내려받기 기능만 빠지고 분석은 동일하게 동작한다).

수정 시 `src/template.html`(Python 빌드용)과 파싱 규칙이 어긋나지 않도록 함께 손볼 것.
