# 제주 에어비앤비 호스팅 시장분석 시스템 — 개발 타당성 검토

작성일: 2026-09-08

## 0. 한 줄 결론

**개발 가능합니다.** 다만 "제주도 내 운영 중인 숙소 + 지역·기간별 평균 점유율과 가격대"를
**정확한 실측치로** 얻는 것은 불가능하고, **공공데이터(정확·무료) + 상용 STR 데이터(추정·유료)를
결합한 추정 모델**로 만들어야 합니다.

그리고 개발보다 먼저 확인해야 할 것이 있습니다 — **제주도는 에어비앤비 합법 운영 요건이
전국에서 가장 까다로운 지역**입니다 (§5 참조). 등록 자격이 없으면 분석 결과는 무의미합니다.

## 1. 요구사항 분해

| 요구 항목 | 획득 난이도 | 가능한 정확도 |
|---|---|---|
| 제주도 내 운영 중인 숙소 목록·수 | 쉬움 | **정확** (인허가 원본 데이터) |
| 지역별(읍면동) 공급량·개폐업 추이 | 쉬움 | **정확** |

## 2. 데이터 소스 옵션 비교

### A. Airbnb 공식 API — ❌ 사용 불가
파트너(PMS·채널매니저)용으로만 개방되며, 제공 범위는 **자기 소유 숙소의 예약/캘린더**입니다.
경쟁 숙소 조회나 시장 통계 API는 존재하지 않습니다.

### B. 상용 STR 데이터 (AirDNA / AirROI / Airbtics / Key Data) — ⭕ 권장
- **AirDNA**: 제주 마켓 대시보드 제공. 지역·월별 ADR, 점유율, RevPAR, 공급량.
  - 요금(2026년 8월 기준 공시): Free 티어 / Research $34·월(연납) / Host $50·월(연납),
    MarketMinder 지역 단위 $19.95·월~. **API는 Enterprise 별도 협상**(고가).
- **AirROI**: 무료 데이터 포털 + 한국 마켓 리포트 제공.
- 장점: 즉시 사용, 법적 리스크 낮음, 추정 모델이 업계 표준.
- 단점: 비용, **읍면동 단위 해상도 부족**(제주시/서귀포시 수준), 원천 데이터 재배포 금지.

### C. Inside Airbnb (무료 공개 데이터셋) — △ 제한적
비상업 목적 무료. 다만 **한국은 커버리지가 서울 중심이고 제주 스냅샷은 사실상 없습니다.**
스냅샷 주기도 도시별로 불규칙합니다. 제주 용도로는 부적합.

### D. 직접 스크래핑 (Airbnb 검색·캘린더 크롤링) — ⚠️ 비권장
기술적으로는 가능하고, Apify 등에 제주 대상으로도 돌릴 수 있는 액터가 다수 있습니다
(캘린더·가격·점유율 추정 액터, 월 $10 수준). 그러나:
- Airbnb 이용약관 위반 → IP·계정 차단
- 국내법: 저작권법상 **데이터베이스제작자 권리**, 부정경쟁방지법 **(카)목 성과물 무단사용**
  — 크롤링 관련 국내 판례가 이미 축적되어 있습니다.
- 호스트명·프로필 사진 수집 시 **개인정보보호법** 이슈
- 서드파티 액터를 쓰더라도 **수집·이용 책임은 이용자에게 귀속**됩니다.
→ 개인 의사결정용 소규모 조회 정도면 현실적 위험은 낮지만, 서비스화·재배포는 하지 마십시오.

### E. 공공데이터 — ⭕⭕ 핵심 기반 (무료·합법·정확)
| 소스 | 내용 | 접근 |
|---|---|---|
| **LOCALDATA** (지방행정인허가데이터) | 숙박업·**농어촌민박** 인허가 전건. 상호/소재지/개폐업일 | 전체 다운로드 + 변경분 Open API |
| 공공데이터포털 `제주특별자치도_관광숙박업현황` | 호텔·호스텔·콘도 구분/상호/소재지/객실수 | 파일/API |
| 행안부 `문화_농어촌민박업` / `관광숙박업` | 전국 단위 동일 스키마 | 파일 |
| 한국관광공사 TourAPI · 제주관광정보 Open API | 숙박·관광지 메타 | API 키 |
| **제주관광 빅데이터 플랫폼** (data.ijto.or.kr) | 입도객, 비짓제주 로그, 수요예측 | 웹/다운로드 |
| 제주관광공사 관광객 실태조사 | 체류일수·숙박유형 분포 | 파일 |

→ **"운영 중인 숙소"와 "지역별 공급량 시계열"은 이 조합만으로 100% 정확하게 산출됩니다.**
   에어비앤비 리스팅과 1:1 매칭은 안 되지만, 시장 공급·경쟁강도 분석에는 오히려 더 신뢰도가 높습니다.

## 3. 점유율의 구조적 한계 (반드시 인지할 것)

Airbnb는 점유율을 공개하지 않습니다. **AirDNA를 포함한 모든 상용 데이터도 추정치입니다.**

1. **캘린더 기반**: 예약 불가일을 수집 → 그러나 *예약됨(booked)* 과 *호스트가 막음(blocked)* 을
   구분할 수 없어 점유율이 과대추정됩니다.
2. **리뷰 기반 (San Francisco Model)**: `리뷰 수 ÷ 리뷰 작성률(≈50%) × 평균 숙박일수`
   → 계절 편차·신규 숙소에서 오차가 큽니다.

**실무 권장**: 두 방식을 **교차검증**하고 점유율을 단일 숫자가 아닌
**구간(예: 38~52%)** 으로 제시하도록 설계하십시오.

> 참고치: AirDNA 기준 제주 전역 평균 점유율은 **약 45%** 수준으로,
> 서울(약 66%)보다 현저히 낮습니다. **공급 과잉 시장**이라는 신호입니다.

## 4. 권장 아키텍처 (3단계, 하이브리드)

```
[Phase 1] 공급·수요 지도 — 무료 공공데이터        2~3주
  LOCALDATA 숙박업/농어촌민박 인허가 (전체 + 월 변경분)
    → 제주 읍면동별 숙소 수, 개·폐업 추이, 업종 구성
  제주 월별 입도 관광객 통계 + 비짓제주 로그
    → 수요 계절성 지수
  산출물: 지역별 공급 밀도 · 경쟁강도 · 성수기 캘린더

[Phase 2] 가격·점유율 벤치마크 — 유료 구독         1~2주
  AirDNA / AirROI 제주 마켓 (지역 × 월 단위 ADR·점유율·RevPAR)
    → Phase 1의 공급 데이터와 지역 코드로 조인
  산출물: 지역 × 기간 매트릭스 (ADR, 점유율 구간, RevPAR)

[Phase 3] 수익 시뮬레이터                          1~2주
  예상 연매출 = ADR × 점유율 × 365 × (1 − 플랫폼수수료)
  − 고정비(임대/대출·관리·청소·세금·보험)
  → 손익분기 점유율, 시나리오(비관/기본/낙관), 지역 순위
```

**기술 스택 제안** (현 저장소 성격과 정합)
- 수집·가공: Python (`requests`, `pandas`), 저장은 DuckDB 또는 SQLite
- 스케줄: GitHub Actions (월 1회 LOCALDATA 변경분 수집)
- 대시보드: **정적 HTML + Chart.js**로 빌드 → 현재 저장소에 이미 구성된
  **GitHub Pages 워크플로를 그대로 재사용** 가능 (별도 서버·비용 0)
- 대안: 로컬에서 돌린다면 Streamlit이 더 빠름

**총 소요**: 4~7주 (1인 기준). Phase 1만이면 2~3주.
**비용**: Phase 1 = ₩0 / Phase 2 = 월 5만원 내외 구독 (Enterprise API 불필요)

## 5. ⚠️ 개발보다 먼저 — 제주 합법 운영 요건

제주는 **외국인관광 도시민박업 등록이 불가**합니다.
2012년 제정 「제주특별자치도 관광진흥 조례」가 **객실 과잉공급 방지**를 이유로 이를 배제했습니다.
서울·부산에서 흔한 "아파트 에어비앤비" 경로가 제주에는 **없습니다.**

따라서 제주에서의 합법 경로는 사실상:

**① 농어촌민박 (가장 현실적)**
- 관할 시·군·구에 **6개월 이상 거주**한 주민 (**법인 불가**)
- **본인이 소유하고 실제 거주하는** 주택
  - 예외: 해당 시군구 3년 이상 거주 + 임차로 2년 이상 민박 운영(행정처분 이력 없음) 등
- 연면적 **230㎡ 미만**의 단독주택 또는 다가구주택
- 농어촌지역에 한함 — 제주는 준농어촌지역에 해당하지 않으나,
  **제주시 일부 동(洞) 주거지역을 농어촌지역으로 지정**하여 동지역에도 약 300개소가 등록되어 있습니다.
  → **대상 필지의 지역 지정 여부를 관할 시청에 반드시 사전 확인**해야 합니다.

**② 일반숙박업 / 생활숙박업 / 호스텔업** — 자본·건축 요건이 훨씬 큼

**③ 영업신고증 제출 의무**
Airbnb는 2024년 10월부터 영업신고 정보 제출을 도입, **2025년 10월부터 전 숙소 전면 적용**했습니다.
미신고 숙소는 리스팅 유지가 불가합니다.

> **권고**: Phase 1 착수와 동시에, 후보 지역의 **농어촌민박 등록 가능 여부**를
> 제주시·서귀포시 담당 부서에 확인하십시오. 이 결과가 분석 대상 지역 자체를 좌우합니다.
> 오히려 이 요건 때문에 **분석 대상이 "내가 등록 가능한 읍면동"으로 크게 좁혀지며,
> 그만큼 개발 범위도 작아집니다.**

## 6. 최종 권고

1. **하십시오**: Phase 1 (공공데이터 기반 공급·수요 지도). 무료·합법·정확하며 2~3주면 됩니다.
2. **하십시오**: Phase 2를 AirDNA 구독 + 수동/반자동 반영으로. Enterprise API는 개인 호스트에게 과투자입니다.
3. **하지 마십시오**: 대규모 Airbnb 스크래핑 파이프라인 구축. 법적 리스크 대비 이득이 적습니다.
4. **먼저 하십시오**: 농어촌민박 등록 자격 확인. 개발 전체의 전제 조건입니다.
